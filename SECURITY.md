# Security policy

## Supported versions

Security fixes go into the latest release; the `latest` image always contains them. Please
update before reporting.

## Reporting a vulnerability

Do **not** open a public issue. Report it privately through
**Security → Report a vulnerability** in this repository on GitHub, with what is affected,
how to reproduce it, and the version (image tag or commit).

You get an answer within a week. Once a fix is released, the advisory is published and you
are credited if you like.
